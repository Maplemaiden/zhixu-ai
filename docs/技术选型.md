# 技术选型（已冻结推荐）

中期交付形式：**演示视频**（非现场答辩为主）。  
中期竖切方法：**风险型决策 · 期望值准则**（知识库第二讲材料最完整，Solver 最好写）。

---

## 总览

| 层级 | 选型 | 理由 |
|------|------|------|
| 前端 | **Vue 3 + Vite** | 好接 API；可逐步复用现有 HTML 原型的交互与文案 |
| 后端 | **Python FastAPI** | 与 NumPy 计算校验同一语言；开发快 |
| 大模型 | **DeepSeek API**（主） | 中文强、便宜，适合学生预算；备选通义千问 |
| Embedding | **DeepSeek / 通义 Embedding**，或本地 **bge-small-zh-v1.5** | 中期可先 API；没额度再改本地 |
| 向量库 | **Chroma**（本地文件） | 零运维，一台电脑可跑通演示 |
| 会话库 | **SQLite** | 轻量，够用到交付 |
| 2D 数字人 | **开源 TalkingHead（或静态 2D 形象）+ edge-tts / 云 TTS** | **零月费**；中期先保证「出声+形象」，口型可用 TalkingHead 或先半身图+音频 |
| 计算 | **NumPy** | 期望值/矩阵类足够 |

不选百度曦灵 3D/高价实时 SDK：贵，且图文才是教学主体。

---

## 2D 数字人怎么落地（分两档）

**中期（保视频）：**  
- 页面右侧/左侧放 2D 形象（美术出图或开源形象）  
- 讲解文本走 TTS 出音频 → 播放；有 TalkingHead 就驱动口型，没有就「播报中」动画  
- 失败则只显示图文步骤（已够录视频）

**交付增强：**  
- 接入 TalkingHead 或低成本 2D 口型方案，按步 `speak` 推送

## 密钥与配置

- 所有 Key 放服务端 `.env`，不进前端、不进 Git  
- 见仓库根目录 `.env.example`

---

## 中期竖切完成标准（录视频用）

1. 进入「期望值准则」知识点 → 分步图文讲解  
2. 可追问（RAG 基于第二讲知识）  
3. 做 1～2 道练习题并判对错  
4. 数字人/TTS 播报至少一步（可降级为纯图文+旁白）
