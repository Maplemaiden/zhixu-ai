## 一、不确定型决策的基本概念

### 1.1 现实背景

不确定型决策在生活中非常常见。例如企业在生产经营中会遇到一些极少发生或应急的事情，此时往往无法明确指出事物在未来将会出现何种状态，而只能了解事物有可能出现哪几种状态。

**例如**：由于无法估计一种新产品的销售前景，在此种情况下，如何确定新产品的产量就是一个不确定型决策问题。

在管理中，有时只能了解事物有可能出现哪几种状态，但是对这几种自然状态出现的可能性有多大无法确切知道，这就是不确定型决策所面临的现实背景。

### 1.2 定义

**不确定型决策**：当决策者只能掌握可能出现的各种状态，而各种状态发生的概率无从知晓时，这种情形下的决策问题称为不确定型决策。

### 1.3 不确定型决策满足的条件

| 序号 | 条件 | 说明 |
|:---:|:---|:---|
| 第一 | 决策主体有明确的决策目标 | 上例中的目标是确定最佳方案，实现最大收益 |
| 第二 | 存在两个或两个以上不以决策者意志为转移的自然状态 | 上例中指三个不同的市场需求状态 |
| 第三 | 存在两个或两个以上可供决策主体选择的决策方案 | — |
| 第四 | 已知各个决策方案在不同自然状态下对应的收益值 | — |

### 1.4 决策准则的必要性

在不确定型决策问题中，各个决策方案的结果都随自然状态的不同而有差异，而不同的自然状态概率又不为决策主体所知。因此，只有确定衡量决策优劣的准则，才能较好地解决此类问题。

在现实中，根据经验的积累，人们总结出了一些公认的决策准则，它们为解决一些极少发生或应急决策问题提供了思路或方法。尽管由这些准则出发也许并不能产生令人满意的决策方案，并不能获得未来实际状态下真正的最优结果，但是舍此并无良策。毕竟，企图在不占有详细资料的前提下做出精确分析是不可能的。（权宜之计）

### 1.5 常用的不确定型决策准则

为了解决不确定型决策问题，提出了以下决策准则：

1. **乐观决策准则**
2. **悲观决策准则**
3. **折中决策准则**
4. **后悔值决策准则**
5. **等概率决策准则**

> **注意**：对不同方案的取舍在很大程度上取决于决策主体的经验、偏好、对自然状态发生情况的判断、心理素质以及对风险的态度，这就使得决策过程带有很强的主观性。
>
> 对同一个决策问题，决策者往往会采用不同的决策准则，而不同的决策准则又对应着各种不同的决策方法，从而带来不同的决策结果。此外，由于缺乏统一的评价标准，无法判断各种决策方法的优劣。

## 三、乐观决策准则（大中取大）

### 3.1 基本思想

决策者对客观发生的自然状态总是抱乐观态度，以乐观的精神寄希望于出现对自己最有利的状态。

- **以收益最大化为目标**：首先找出各方案的最大收益值，然后选择这些最大收益值中最大者所对应的方案作为最优方案。此种情形的乐观决策准则又称为**最大收益值准则**。
- **以损失最小化为目标**：从各个方案的最小损失值中选择损失最小者所对应的方案作为最优方案。此种情形的乐观决策准则又称**最小损失值决策准则**。

### 3.2 决策步骤

1. 找出每个方案在各种自然状态下的最大收益值：maxⱼ{aᵢⱼ}
2. 在所有方案的最大收益值中再取最大值：maxᵢ{maxⱼ{aᵢⱼ}}
3. 该最大值对应的方案即为最优决策方案。

### 3.3 例题

#### 例 1：企业生产线建设问题

**表 4-4 某企业生产线建设问题决策收益表（净现值）**

| 方案 | 高需求（θ₁） | 中需求（θ₂） | 低需求（θ₃） | maxⱼ{aᵢⱼ} |
|:---:|:---:|:---:|:---:|:---:|
| a₁ | 1000 | 600 | -200 | **1000** |
| a₂ | 750 | 450 | 50 | 750 |
| a₃ | 300 | 300 | 80 | 300 |
| 决策 | maxᵢ{maxⱼ{aᵢⱼ}} | | | **1000** |

**计算过程**：
- a₁ 的最大收益：max{1000, 600, -200} = 1000
- a₂ 的最大收益：max{750, 450, 50} = 750
- a₃ 的最大收益：max{300, 300, 80} = 300
- 所有方案最大收益中的最大者：max{1000, 750, 300} = 1000

**结论**：最优决策方案为 **a₁**。

#### 例 2：水位决策问题

某决策问题的收益矩阵模型如表 4-5 所示，单位：万元。

**表 4-5 决策矩阵模型**

|:---:|:---:|:---:|:---:|:---:|
| a₁ | -2 | -2 | -2 | -2 |
| a₂ | 0 | -5 | -12 | **0** |
| a₃ | -1.2 | -1.2 | -13.2 | -1.2 |
| 决策 | maxᵢ{maxⱼ{aᵢⱼ}} | | | **0** |

**计算过程**：
- a₁ 的最大收益：max{-2, -2, -2} = -2
- a₂ 的最大收益：max{0, -5, -12} = 0
- a₃ 的最大收益：max{-1.2, -1.2, -13.2} = -1.2
- 所有方案最大收益中的最大者：max{-2, 0, -1.2} = 0

**结论**：最优决策方案为 **a₂**。

> **难点提示**：此类问题的关键在于找出可能的状态，并算出损益值。

### 3.4 对乐观准则的评价

**乐观准则（大中取大）的优缺点**：

- **优点**：体现了决策者自信乐观的性格、进取的精神和冒险偏好，认为不管自己采取哪种方案，将来总会发生对该方案有利的自然状态。
- **缺点**：
  - 只看中最大收益，忽略了其他有价值的信息；
  - 无论最坏情况下的损失有多大，都不能影响决策者对取得最大收益方案的选择；
  - 这种决策方法本身存在巨大的风险，如果实际发生的状态劣于决策者的主观预期，决策者可能蒙受巨大损失。

## 四、悲观决策准则（小中取大）

### 4.1 基本思想

与乐观决策准则相反，悲观决策准则对客观情况总持悲观态度，认为最坏状态出现的可能性较大，即认为对于任何一种方案，都是收益最小的状态发生。

**悲观决策准则**：从各个行动方案的最小收益中选取收益值最大的方案作为最优方案。它反映了决策者的一种悲观情绪，体现了决策者的一种保守思维方式。

### 4.2 决策步骤

1. 找出每个方案在各种自然状态下的最小收益值：minⱼ{aᵢⱼ}
2. 在所有方案的最小收益值中取最大值：maxᵢ{minⱼ{aᵢⱼ}}
3. 该最大值对应的方案即为最优决策方案。

### 4.3 例题

#### 例 1：企业生产线建设问题

**表 4-7 某企业生产线建设问题决策收益表（净现值）**

| 方案 | 高需求（θ₁） | 中需求（θ₂） | 低需求（θ₃） | minⱼ{aᵢⱼ} |
|:---:|:---:|:---:|:---:|:---:|
| a₁ | 1000 | 600 | -200 | -200 |
| a₂ | 750 | 450 | 50 | 50 |
| a₃ | 300 | 300 | 80 | **80** |
| 决策 | maxᵢ{minⱼ{aᵢⱼ}} | | | **80** |

**计算过程**：
- a₁ 的最小收益：min{1000, 600, -200} = -200
- a₂ 的最小收益：min{750, 450, 50} = 50
- a₃ 的最小收益：min{300, 300, 80} = 80
- 所有方案最小收益中的最大者：max{-200, 50, 80} = 80

**结论**：最优决策方案为 **a₃**。

#### 例 2：水位决策问题

**表 4-8 决策矩阵模型**

| 方案 | 1米以下 | 1～2米 | 2米以上 | minⱼ{aᵢⱼ} |
|:---:|:---:|:---:|:---:|:---:|
| a₁ | -2 | -2 | -2 | **-2** |
| a₂ | 0 | -5 | -12 | -12 |
| a₃ | -1.2 | -1.2 | -13.2 | -13.2 |
| 决策 | maxᵢ{minⱼ{aᵢⱼ}} | | | **-2** |

**计算过程**：
- a₁ 的最小收益：min{-2, -2, -2} = -2
- a₂ 的最小收益：min{0, -5, -12} = -12
- a₃ 的最小收益：min{-1.2, -1.2, -13.2} = -13.2
- 所有方案最小收益中的最大者：max{-2, -12, -13.2} = -2

**结论**：最优决策方案为 **a₁**。

### 4.4 对悲观准则的评价

**悲观准则（小中取大）的优缺点**：

- **优点**：
  - 要求决策者在处理问题时从最不利的结果出发，凡事做最坏的打算；
  - 较多考虑自身能否承受决策失误带来的打击；
  - 略显保守，但由于是要在"最不利"中找出"最有利"的方案，所以留有很大的余地；
  - 适用于把握性很小、损失很大的决策问题。
- **缺点**：
  - 决策者处理问题时谨慎小心，追求稳妥，思想较为保守消极；
  - 反映了决策者对出现有利的自然状态信心不足，态度悲观；
  - 只看到了最坏情况下的收益数据，忽略了其他有价值的信息。

## 五、折中决策准则

### 5.1 基本思想

乐观决策准则和悲观决策准则分别是从最好和最坏的结果出发进行决策的，他们对自然状态的假设都过于极端：前者认为总会出现最有利的情况，而后者则认为总会出现最不利的情况。

- 乐观决策准则过于冒进；
- 悲观决策准则过于保守；
- 这两种准则的思想明显有些偏激。

在实际的决策过程中，决策者一般既不会认为未来将一帆风顺，也不会表现出极度的悲观情绪，而是往往采取折中的态度。**折中决策准则**就是基于这种思路产生的一种决策方法。

折中决策准则认为各个行动方案既不会出现最好的条件结果值，也不会出现最坏的条件结果值，而是出现最好结果值和最坏结果值之间的某个折中值。决策者只需要在各个行动方案的折中值里选择最大的那个，其对应的行动方案即为最优决策方案。

### 5.2 乐观系数

设 α 为乐观系数，则折中收益值计算公式为：

$$
CV_i = \alpha \cdot \max_j\{a_{ij}\} + (1-\alpha) \cdot \min_j\{a_{ij}\}
$$

其中：
- α ∈ [0, 1]，表示决策者对状态乐观程度的判断；
- 当 α = 1 时，折中准则等同于乐观准则；
- 当 α = 0 时，折中准则等同于悲观准则。

### 5.3 决策步骤

1. 确定乐观系数 α 的值；
2. 对每个方案，找出最大收益值 maxⱼ{aᵢⱼ} 和最小收益值 minⱼ{aᵢⱼ}；
3. 根据公式计算各方案的折中收益值 CVᵢ；
4. 选择折中收益值最大的方案为最优决策方案：maxᵢ{CVᵢ}。

### 5.4 例题

#### 例 1：企业生产线建设问题

**表 4-10 某企业生产线建设问题决策收益表（净现值）**

| 方案 | 高需求（θ₁） | 中需求（θ₂） | 低需求（θ₃） | α=0.3 | α=0.5 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| a₁ | 1000 | 600 | -200 | 160 | 400 |
| a₂ | 750 | 450 | 50 | 260 | 400 |
| a₃ | 300 | 300 | 80 | 146 | 190 |
| 决策 | maxᵢ{CVᵢ} | | | **260** | **400** |

**当 α = 0.3 时的计算过程**：
- a₁：CV₁ = 0.3×1000 + (1-0.3)×(-200) = 300 - 140 = **160**
- a₂：CV₂ = 0.3×750 + (1-0.3)×50 = 225 + 35 = **260**
- a₃：CV₃ = 0.3×300 + (1-0.3)×80 = 90 + 56 = **146**
- 最大折中收益值：max{160, 260, 146} = **260**

**结论（α=0.3）**：最优决策方案为 **a₂**。

**当 α = 0.5 时的计算过程**：
- a₁：CV₁ = 0.5×1000 + (1-0.5)×(-200) = 500 - 100 = **400**
- a₂：CV₂ = 0.5×750 + (1-0.5)×50 = 375 + 25 = **400**
- a₃：CV₃ = 0.5×300 + (1-0.5)×80 = 150 + 40 = **190**
- 最大折中收益值：max{400, 400, 190} = **400**

**结论（α=0.5）**：最优决策方案为 **a₁ 或 a₂**（两者折中收益值相同）。

#### 例 2：水位决策问题

**表 4-11 决策矩阵模型**

| 方案 | 1米以下 | 1～2米 | 2米以上 | CVᵢ |
|:---:|:---:|:---:|:---:|:---:|
| a₁ | -2 | -2 | -2 | **-2** |
| a₂ | 0 | -5 | -12 | -4.8 |
| a₃ | -1.2 | -1.2 | -13.2 | -6 |
| 决策 | maxᵢ{CVᵢ} | | | **-2** |

**计算过程**（假设 α 给定）：
- a₁ 的最大收益和最小收益均为 -2，故 CV₁ = -2
- a₂：CV₂ 计算结果为 -4.8
- a₃：CV₃ 计算结果为 -6
- 最大折中收益值：max{-2, -4.8, -6} = -2

**结论**：最优决策方案为 **a₁**。

### 5.5 对折中决策准则的评价

- **优点**：介于乐观决策准则和悲观决策准则之间的一种决策方法，是一种既稳妥又积极的决策方法。虽不能保证一定获得最佳结果，但对于决策者而言仍然具有一定的有利条件。
- **缺点一**：乐观系数的确定存在困难。乐观系数的值取决于决策者的主观判断，使决策过程客观性减弱，降低决策结果的可靠性。
- **缺点二**：信息利用不充分，只考虑最大收益值和最小收益值，忽略了其他收益值。

> **注意**：折中决策准则在某些情况下可能出现违反直觉的结果，需结合具体问题谨慎使用。

## 六、后悔值决策准则（萨凡奇准则）

### 6.1 基本思想

在理想情况下，决策者进行决策时选择收益最大或者损失最小的方案作为最优方案。然而实际情况往往不是这样。在不确定型决策问题中，由于未来自然状态不确定性的影响，决策者在最初可能并未采取理想情况下的最优方案，而是采取了其他方案。

一旦决策者后来发现自己当初舍优取劣，错失最大收益的机会，就会感觉到后悔。基于避免现在的选择造成未来太大遗憾的思想，**萨凡奇（Savage）提出了后悔值准则**，将"后悔"这一主观感觉数量化，并以该值的大小作为决策依据。

### 6.2 后悔值的确定

在未来一定自然状态下，实际所选方案的收益值与最优方案的收益值之差越大，后悔值就越大。

**后悔值决策准则的基本思想**：假设各个方案最可能出现后悔值最大的情况，从各个方案的最大后悔值中选择后悔值最小的方案作为最优方案。

即：
1. 首先求出各方案在各自然状态下的后悔值 rᵢⱼ；
2. 然后找出各方案的最大后悔值 maxⱼ{rᵢⱼ}；
3. 再从这些最大后悔值中选出最小后悔值 minᵢ{maxⱼ{rᵢⱼ}}；
4. 其所对应的方案就是最优决策方案。

**后悔值计算公式**：

$$
r_{ij} = \max_k\{a_{kj}\} - a_{ij}
$$

其中：
- maxₖ{aₖⱼ} 表示在自然状态 θⱼ 下，所有方案中的最大收益值；
- aᵢⱼ 表示方案 aᵢ 在自然状态 θⱼ 下的收益值。

### 6.3 决策步骤

1. 对每个自然状态 θⱼ，找出该状态下的最大收益值；
2. 计算各方案在各状态下的后悔值 rᵢⱼ；
3. 找出每个方案的最大后悔值 maxⱼ{rᵢⱼ}；
4. 在所有方案的最大后悔值中选取最小值 minᵢ{maxⱼ{rᵢⱼ}}；
5. 该最小值对应的方案即为最优决策方案。

### 6.4 例题

#### 例 1：企业生产线建设问题

**已知收益表**：

| 方案 | 高需求（θ₁） | 中需求（θ₂） | 低需求（θ₃） |
|:---:|:---:|:---:|:---:|
| a₁ | 1000 | 600 | -200 |
| a₂ | 750 | 450 | 50 |
| a₃ | 300 | 300 | 80 |

**第一步：确定各自然状态下的最优收益**
- θ₁（高需求）下最优收益：max{1000, 750, 300} = **1000**
- θ₂（中需求）下最优收益：max{600, 450, 300} = **600**
- θ₃（低需求）下最优收益：max{-200, 50, 80} = **80**

**第二步：计算后悔值**

- **方案 a₁**：
  - r₁₁ = 1000 - 1000 = **0**
  - r₁₂ = 600 - 600 = **0**
  - r₁₃ = 80 - (-200) = **280**

- **方案 a₂**：
  - r₂₁ = 1000 - 750 = **250**
  - r₂₂ = 600 - 450 = **150**
  - r₂₃ = 80 - 50 = **30**

- **方案 a₃**：
  - r₃₁ = 1000 - 300 = **700**
  - r₃₂ = 600 - 300 = **300**
  - r₃₃ = 80 - 80 = **0**

**第三步：构建后悔值矩阵并决策**

**表 4-14 后悔值决策矩阵模型**

| 方案 | 高需求（θ₁） | 中需求（θ₂） | 低需求（θ₃） | maxⱼ{rᵢⱼ} |
|:---:|:---:|:---:|:---:|:---:|
| a₁ | 0 | 0 | 280 | 280 |
| a₂ | 250 | 150 | 30 | **250** |
| a₃ | 700 | 300 | 0 | 700 |
| 决策 | minᵢ{maxⱼ{rᵢⱼ}} | | | **250** |

**第四步：确定最优方案**
- a₁ 的最大后悔值：max{0, 0, 280} = 280
- a₂ 的最大后悔值：max{250, 150, 30} = 250
- a₃ 的最大后悔值：max{700, 300, 0} = 700
- 所有方案最大后悔值中的最小者：min{280, 250, 700} = **250**

**结论**：最优决策方案为 **a₂**。

#### 例 2：建筑公司设备安置问题

| 方案 | 1米以下（θ₁） | 1～2米（θ₂） | 2米以上（θ₃） |
|:---:|:---:|:---:|:---:|

**第一步：确定各自然状态下的最优收益**
- θ₁（1米以下）下最优收益：max{-2, 0, -1.2} = **0**

**第二步：计算后悔值**

  - r₁₁ = 0 - (-2) = **2**
  - r₁₂ = -1.2 - (-2) = **0.8**
  - r₁₃ = -2 - (-2) = **0**

- **方案 a₂**：
  - r₂₁ = 0 - 0 = **0**
  - r₂₂ = -1.2 - (-5) = **3.8**
  - r₂₃ = -2 - (-12) = **10**

- **方案 a₃**：
  - r₃₁ = 0 - (-1.2) = **1.2**
  - r₃₂ = -1.2 - (-1.2) = **0**
  - r₃₃ = -2 - (-13.2) = **11.2**

**第三步：构建后悔值矩阵并决策**

| 方案 | 1米以下 | 1～2米 | 2米以上 | maxⱼ{rᵢⱼ} |

- a₂ 的最大后悔值：max{0, 3.8, 10} = 10
- a₃ 的最大后悔值：max{1.2, 0, 11.2} = 11.2
- 所有方案最大后悔值中的最小者：min{2, 10, 11.2} = **2**

### 6.5 对后悔值决策准则的评价

- **优点**：
  - 采用该准则的决策者对未来出现的"最有利状态"信心不足，但又不愿意失去机会，所以在追求最优结果的同时，努力减少决策失误的机会成本；
  - 体现了决策者不追求收益最高但求遗憾最小的保守性格；
  - 从避免较大决策失误的角度进行决策，是一个比较稳妥的决策方法，并且要比只从最坏决策考虑的悲观决策准则方法更合乎情理。
- **缺点**：计算过程相对复杂，需要先构建后悔值矩阵。

## 七、等概率决策准则

### 7.1 基本思想

乐观决策准则、悲观决策准则和折中决策准则的共同缺陷是没有充分利用收益函数所包含的全部信息，在很大程度上会影响决策的准确性。

等概率准则认为：在各自然状态发生概率不清楚的时候，只能认为各状态发生的概率相等。按相等的概率求出各个方案的条件收益期望值，最大期望收益值对应的方案即为最优决策方案。

### 7.2 决策步骤

1. 设各自然状态发生的概率相等，即 P(θⱼ) = 1/n；
2. 计算各方案在各自然状态下的期望收益值 Eᵢ[aᵢⱼ] = (1/n) × aᵢⱼ；
3. 计算各方案的期望收益总和：∑ⱼEᵢ[aᵢⱼ]；
4. 选择期望收益总和最大的方案为最优决策方案：maxᵢ{∑ⱼEᵢ[aᵢⱼ]}。

### 7.3 例题

#### 例 1：企业生产线建设问题

**已知收益表**：

| 方案 | 高需求（θ₁） | 中需求（θ₂） | 低需求（θ₃） |
|:---:|:---:|:---:|:---:|
| a₁ | 1000 | 600 | -200 |
| a₂ | 750 | 450 | 50 |
| a₃ | 300 | 300 | 80 |

**第一步：计算各方案在每种自然状态下的期望收益值**

- **方案 a₁**：
  - E₁[a₁₁] = (1/3) × 1000 = **333.3**
  - E₁[a₁₂] = (1/3) × 600 = **200**
  - E₁[a₁₃] = (1/3) × (-200) = **-66.7**

- **方案 a₂**：
  - E₂[a₂₁] = (1/3) × 750 = **250**
  - E₂[a₂₂] = (1/3) × 450 = **150**
  - E₂[a₂₃] = (1/3) × 50 = **16.7**

- **方案 a₃**：
  - E₃[a₃₁] = (1/3) × 300 = **100**
  - E₃[a₃₂] = (1/3) × 300 = **100**
  - E₃[a₃₃] = (1/3) × 80 ≈ **26.7**

**第二步：构造等概率决策准则的决策矩阵模型**

**表 4-17 等概率决策准则的决策矩阵模型**

| 方案 | θ₁（1/3） | θ₂（1/3） | θ₃（1/3） | ∑ⱼEᵢ[aᵢⱼ] |
|:---:|:---:|:---:|:---:|:---:|
| a₁ | 333.3 | 200 | -66.7 | **466.7** |
| a₂ | 250 | 150 | 16.7 | 416.7 |
| a₃ | 100 | 100 | 26.7 | 226.7 |
| 决策 | maxᵢ{∑ⱼEᵢ[aᵢⱼ]} | | | **466.7** |

**第三步：确定最优方案**
- a₁ 的期望收益总和：333.3 + 200 + (-66.7) = **466.7**
- a₂ 的期望收益总和：250 + 150 + 16.7 = **416.7**
- a₃ 的期望收益总和：100 + 100 + 26.7 = **226.7**
- 最大期望收益：max{466.7, 416.7, 226.7} = **466.7**

**结论**：最优决策方案为 **a₁**。

#### 例 2：水位决策问题

**已知收益表**：

| 方案 | 1米以下 | 1～2米 | 2米以上 |
|:---:|:---:|:---:|:---:|
| a₁ | -2 | -2 | -2 |
| a₂ | 0 | -5 | -12 |
| a₃ | -1.2 | -1.2 | -13.2 |

**第一步：计算各方案在每种自然状态下的期望收益值**

- **方案 a₁**：
  - E₁[a₁₁] = E₁[a₁₂] = E₁[a₁₃] = (1/3) × (-2) = **-0.67**

- **方案 a₂**：
  - E₂[a₂₁] = (1/3) × 0 = **0**
  - E₂[a₂₂] = (1/3) × (-5) = **-1.67**
  - E₂[a₂₃] = (1/3) × (-12) = **-4**

- **方案 a₃**：
  - E₃[a₃₁] = E₃[a₃₂] = (1/3) × (-1.2) = **-0.4**
  - E₃[a₃₃] = (1/3) × (-13.2) = **-4.4**

**第二步：构造等概率决策准则的决策矩阵模型**

**表 4-18 等概率决策准则的决策矩阵模型**

| 方案 | 1米以下（1/3） | 1～2米（1/3） | 2米以上（1/3） | ∑ⱼEᵢ[aᵢⱼ] |
|:---:|:---:|:---:|:---:|:---:|
| a₁ | -0.67 | -0.67 | -0.67 | **-2.01** |
| a₂ | 0 | -1.67 | -4 | -5.67 |
| a₃ | -0.4 | -0.4 | -4.4 | -5.2 |
| 决策 | maxᵢ{∑ⱼEᵢ[aᵢⱼ]} | | | **-2.01** |

**第三步：确定最优方案**
- a₁ 的期望收益总和：-0.67 + (-0.67) + (-0.67) = **-2.01**
- a₂ 的期望收益总和：0 + (-1.67) + (-4) = **-5.67**
- a₃ 的期望收益总和：-0.4 + (-0.4) + (-4.4) = **-5.2**
- 最大期望收益：max{-2.01, -5.67, -5.2} = **-2.01**

**结论**：最优决策方案为 **a₁**。

### 7.4 对等概率决策准则的评价

- **优点**：
  - 假设各自然状态出现的概率相等，将不确定型决策问题转化为风险型决策问题来处理；
  - 适用于决策者对未来自然状态没有一点感觉，以至于连事物发展的趋势都不能把握的情况。
- **缺点**：
  - 由于客观上等概率出现的可能性极小，难与实际相符，所以这种决策准则有其局限性；
  - 各自然状态对行动的影响程度是不同的，按照相等的权重计算出的等概率收益值不能准确反映方案的实际期望值，得到的决策结果不甚可靠。

## 八、各决策准则对比总结

| 决策准则 | 基本思想 | 决策依据 | 决策者特点 | 适用场景 |
|:---:|:---|:---|:---|:---|
| **乐观准则** | 寄希望于最有利状态 | maxⱼ{aᵢⱼ} 中再取 max | 自信、进取、冒险 | 风险承受能力强的决策者 |
| **悲观准则** | 认为最坏状态易出现 | minⱼ{aᵢⱼ} 中再取 max | 谨慎、保守、稳妥 | 把握性很小、损失很大的问题 |
| **折中准则** | 最好与最坏之间的折中 | α·max + (1-α)·min | 既积极又稳妥 | 不愿极端冒险或保守的决策者 |
| **后悔值准则** | 最小化最大后悔值 | 后悔值矩阵的 min-max | 不求收益最高但求遗憾最小 | 重视机会成本、避免决策失误 |
| **等概率准则** | 各状态概率相等 | 期望收益最大 | 对未来状态无主观判断 | 完全无法判断状态趋势时 |
