## 二、课程引入：为什么要学习DEA

通过四个引例，逐步说明传统效率评价方法的局限，引出数据包络分析方法的必要性。

### 引例1：单投入单产出（可直接比较）

设有A、B两个工厂生产相同的产品：

| 工厂 | 投入（元） | 销售额（元） |
| --- | --- | --- |
| A | 100 | 200 |
| B | 95 | 205 |

**分析**：B工厂投入更少、产出更多，因此B工厂表现更为优异。此时可用"产出/投入"简单比较。

### 引例2：单投入单产出（仍可比较）

设有A、B两个工厂生产相同的产品：

| 工厂 | 投入（元） | 销售额（元） |
| --- | --- | --- |
| A | 100 | 200 |
| B | 104 | 210 |

**分析**：A的效率比为 200/100 = 2，B的效率比为 210/104 ≈ 2.02。B工厂表现略优，仍可用单一比率比较。

### 引例3：多投入单产出（可引入权重）

设有A、B两个工厂生产相同的产品，均需要经过甲、乙两道工序。当同时产出1万元收益时，投入如下：

| 工厂 | 工序甲（万元） | 工序乙（万元） | 收益（万元） |
| --- | --- | --- | --- |
| A | 0.3 | 0.2 | 1.0 |
| B | 0.2 | 0.4 | 1.0 |

**分析**：总投入A为0.5万元，B为0.6万元，A工厂表现更优。此例虽有两个投入，但可加总为单一成本指标，仍可比较。

### 引例4：多投入且量纲不同（传统方法失效）

设有A、B、C三个工厂生产相同的产品，为产出100万元净利润，投入如下：

| 工厂 | 人力（个） | 原料（公斤） | 净利润（万元） |
| --- | --- | --- | --- |
| A | 25 | 1800 | 100 |
| B | 40 | 1500 | 100 |
| C | 35 | 1700 | 100 |

**分析**：
- 此例中两项投入"人力"和"原料"量纲不同，无法直接相加。
- 若强行给不同指标赋权重，又带有主观性。
- **核心难点**：量纲（单位）不同，难以解决，因此需要引入DEA方法。

## 三、DEA的起源与基本概念

### 1. DEA的起源

**DEA**（Data Envelopment Analysis）又称**数据包络分析**，由著名运筹学家**查恩斯（Charnes）、库珀（Cooper）和罗兹（Rhodes）于1978年**首先提出，用于评价相同部门间的**相对有效性**（因此也称为**DEA有效**）。随后DEA方法得到了长足的发展，并且不断完善。

DEA方法已成为运筹学研究的一个新领域。第一个成功的应用案例就是评价为智障儿童开设公立学校项目的效果。随后DEA方法在经济综合评价、企业技术进步分析、投资项目评价等方面得到了广泛应用。

### 2. 决策单元（DMU）

在经济社会管理中，常常需要对具有相同类型的部门、企业或者同一企业不同时期的相对效率进行评价，这些部门、企业或时期称为**决策单元**（Decision Making Unit，DMU）。

### 3. 投入指标与产出指标

评价的依据是决策单元的一组投入和一组产出数据。

- **投入指标**：决策单元在经济社会和管理活动中需要耗费的经济量（如固定资产原值、开发资金、职工人数等）。
- **产出指标**：决策单元在某种投入要素下，经济活动产生的成效的经济量（如总产值、利税总额、产品数量）。

### 4. 投入产出数据结构

设有n个决策单元，每个决策单元有m项投入、s项产出。一般将投入产出数据整理为如下形式：

|  | 决策单元1 | 决策单元2 | ... | 决策单元n |
| --- | --- | --- | --- | --- |
| 投入1 | x₁₁ | x₁₂ | ... | x₁ₙ |
| 投入2 | x₂₁ | x₂₂ | ... | x₂ₙ |
| ... | ... | ... | ... | ... |
| 投入m | xₘ₁ | xₘ₂ | ... | xₘₙ |
| 产出1 | y₁₁ | y₁₂ | ... | y₁ₙ |
| 产出2 | y₂₁ | y₂₂ | ... | y₂ₙ |
| ... | ... | ... | ... | ... |
| 产出s | yₛ₁ | yₛ₂ | ... | yₛₙ |

### 5. 学校效率评价的实例

现有4所学校，其投入数据如下：

|  | 学校1 | 学校2 | 学校3 | 学校4 |
| --- | --- | --- | --- | --- |
| 教职工人数（名） | 25 | 40 | 35 | 20 |
| 建筑面积（平方米） | 1800 | 1500 | 1700 | 2500 |

**问题**：应该如何评判学校的效率？

## 四、DEA的C²R模型

### 1. 生产前沿面的直观解释

以学校效率评价为例，横轴表示教职工人数，纵轴表示建筑面积，产出均假定为培养800名学生。各校投入在二维平面上形成若干点。其中部分点位于由这些点围成的"下边界"上，这些点就称为**生产前沿面**上的点。

**结论**：
- 就培养800名学生来看，s₁、s₂、s₄三所学校处于**帕累托最优状态**，即不可能在保持其中一项投入不变的情况下，减少另一项投入的水平而仍然达到培养800名学生的目的。
- 由s₁、s₂、s₄三点构成的折线称为**生产前沿面**。
- 凡是在生产前沿面上的点的投入状态均为帕累托最优。

例如，s₁和s₄连线的中点M的坐标为（22.5，2150），即用22.5名教职工和2150平方米的建筑面积可以组成培养800名学生的学校。

### 2. 生产前沿面的定义

所谓生产前沿面是生产可行集的一条**数据包络线**，它是现有绩效水平下举办800名学生规模学校，需要投入教职工和教室面积的**最低极限**。称处在生产前沿面上的点为**DEA有效**。显然s₃并非DEA有效。

### 3. 效率评价指标

设投入指标和产出指标的权系数向量分别为：

- 投入权系数向量：v = (v₁, v₂, ..., vₘ)ᵀ
- 产出权系数向量：u = (u₁, u₂, ..., uₛ)ᵀ

对每一个决策单元j，定义效率评价指标：

$$h_j = \frac{\sum_{r=1}^{s} u_r y_{rj}}{\sum_{i=1}^{m} v_i x_{ij}}$$

效率评价指标hⱼ表示第j个决策单元多投入指标产出所取得的经济效率。可以适当选择权系数u和v，使得hⱼ ≤ 1。

### 4. C²R分式规划模型

下面建立评价第j₀个决策单元相对有效性的C²R模型。设第j₀个决策单元的投入向量和产出向量分别为：

$$x_0 = (x_{1j_0}, x_{2j_0}, ..., x_{mj_0})^T$$
$$y_0 = (y_{1j_0}, y_{2j_0}, ..., y_{sj_0})^T$$

效率评价指标h₀ = hⱼ₀。在效率评价指标hⱼ（j = 1, 2, ..., n）的约束条件下确定权系数u和v，使得h₀达到最大值。构造最优化模型：

$$\max h_0 = \frac{\sum_{r=1}^{s} u_r y_{rj_0}}{\sum_{i=1}^{m} v_i x_{ij_0}}$$

s.t.

$$\frac{\sum_{r=1}^{s} u_r y_{rj}}{\sum_{i=1}^{m} v_i x_{ij}} \leq 1, \quad j = 1, 2, ..., n$$

$$v \geq 0, \quad u \geq 0$$

此模型称为**C²R模型**。用C²R模型评价第j₀个决策单元的有效性，是相对于其他决策单元而言的，故称为评价**相对有效性**的DEA模型。

上述模型可转化为矩阵形式。记：

$$x_j = (x_{1j}, x_{2j}, ..., x_{mj})^T$$
$$y_j = (y_{1j}, y_{2j}, ..., y_{sj})^T$$

则模型为：

$$\max h_0 = \frac{u^T y_0}{v^T x_0}$$

s.t.

$$\frac{u^T y_j}{v^T x_j} \leq 1, \quad j = 1, 2, ..., n$$

$$v \geq 0, \quad u \geq 0$$

### 5. 分式规划转化为线性规划

由于上述模型P̄是一个**分式规划**，需要将其转化为一个等价的线性规划问题。令：

$$t = \frac{1}{v^T x_0}, \quad w = tv, \quad \mu = tu$$

则原分式规划可化为线性规划（P）：

$$\max V_P = \mu^T y_0$$

s.t.

$$w^T x_j - \mu^T y_j \geq 0, \quad j = 1, 2, ..., n$$

$$w^T x_0 = 1$$

$$w \geq 0, \quad \mu \geq 0$$

### 6. 对偶问题

线性规划问题（P）的对偶问题（D）为：

$$\min V_D = \theta$$

s.t.

$$\sum_{j=1}^{n} x_j \lambda_j + s^- = \theta x_0$$

$$\sum_{j=1}^{n} y_j \lambda_j - s^+ = y_0$$

$$\lambda_j \geq 0, \quad j = 1, 2, ..., n$$

$$s^+ \geq 0, \quad s^- \geq 0$$

式中，s⁻ = (s₁⁻, s₂⁻, ..., sₘ⁻)ᵀ为投入松弛变量，s⁺ = (s₁⁺, s₂⁺, ..., sₛ⁺)ᵀ为产出松弛变量。

## 五、评价DEA系统的有效性：另一种思路

### 1. 核心思想

判断某一个决策单元是否是DEA有效，关键在于是否能够找到一个新的决策单元，并且：

1. 新的决策单元的投入不大于该决策单元的投入；
2. 新的决策单元的收益不小于该决策单元的收益。

若存在，则该决策单元不是DEA有效；若不存在，则该决策单元DEA有效。

### 2. 构造假想决策单元

现在需要衡量某一个决策单元j₀是否DEA有效，是否处于由包络线组成的生产前沿面上。为此先构造一个由n个决策单元线性组合的假想决策单元。

这个假想决策单元的第i项投入为：

$$\sum_{j=1}^{n} \lambda_j x_{ij}, \quad i = 1, 2, ..., m$$

该假想单元的第r项产出为：

$$\sum_{j=1}^{n} \lambda_j y_{rj}, \quad r = 1, 2, ..., s$$

并且满足：

$$\sum_{j=1}^{n} \lambda_j = 1, \quad \lambda_j \geq 0$$

### 3. DEA有效性条件

如果这个假想的单元的各项产出均不低于j₀决策单元的各项产出，它的各项投入均不高于j₀决策单元的各项投入，则有：

$$\sum_{j=1}^{n} \lambda_j y_{rj} \geq y_{rj_0}, \quad r = 1, 2, ..., s$$

$$\sum_{j=1}^{n} \lambda_j x_{ij} \leq E \cdot x_{ij_0}, \quad i = 1, 2, ..., m; \quad E \leq 1$$

$$\sum_{j=1}^{n} \lambda_j = 1, \quad \lambda_j \geq 0, \quad j = 1, 2, ..., n$$

### 4. 线性规划模型

基于上述分析，得到如下线性规划模型：

$$\min E$$

s.t.

$$\sum_{j=1}^{n} \lambda_j y_{rj} \geq y_{rj_0}, \quad r = 1, 2, ..., s$$

$$\sum_{j=1}^{n} \lambda_j x_{ij} \leq E \cdot x_{ij_0}, \quad i = 1, 2, ..., m; \quad E \leq 1$$

$$\sum_{j=1}^{n} \lambda_j = 1, \quad \lambda_j \geq 0, \quad j = 1, 2, ..., n$$

**判定规则**：若求解结果有E < 1，则j₀决策单元非DEA有效；否则j₀决策单元DEA有效。

## 六、例题讲解

### 例题：振华银行分理处DEA有效性评价

**例8**：振华银行的4个分理处的投入产出情况如表1-16所示（产出单位：处理笔数/月）。要求分别确定各分理处的运行是否DEA有效。

**表1-16 振华银行4个分理处投入产出表**

| 分理处 | 职员数/人 | 营业面积/m² | 储蓄存取 | 贷款 | 中间业务 |
| --- | --- | --- | --- | --- | --- |
| 分理处1 | 15 | 140 | 1800 | 200 | 1600 |
| 分理处2 | 20 | 130 | 1000 | 350 | 1000 |
| 分理处3 | 21 | 120 | 800 | 450 | 1300 |
| 分理处4 | 20 | 135 | 900 | 420 | 1500 |

**投入指标**：职员数、营业面积

**产出指标**：储蓄存取、贷款、中间业务

### 建立分理处1的线性规划模型

以分理处1为被评价对象（j₀ = 1），建立线性规划模型：

$$\min E$$

s.t.

$$1800\lambda_1 + 1000\lambda_2 + 800\lambda_3 + 900\lambda_4 \geq 1800$$

$$200\lambda_1 + 350\lambda_2 + 450\lambda_3 + 420\lambda_4 \geq 200$$

$$1600\lambda_1 + 1000\lambda_2 + 1300\lambda_3 + 1500\lambda_4 \geq 1600$$

$$15\lambda_1 + 20\lambda_2 + 21\lambda_3 + 20\lambda_4 \leq 15E$$

$$140\lambda_1 + 130\lambda_2 + 120\lambda_3 + 135\lambda_4 \leq 140E$$

$$\lambda_1 + \lambda_2 + \lambda_3 + \lambda_4 = 1$$

$$\lambda_j \geq 0, \quad j = 1, 2, 3, 4$$

### 求解结果与分析

**求解结果**：E = 1，说明分理处1的运行为DEA有效。

此外，在计算分理处3和分理处4时，E = 1，表明分理处3和分理处4均DEA有效。

对于分理处2，求得E = 0.966，λ₁ = 0.28，λ₂ = λ₄ = 0，λ₃ = 0.72，所以分理处2运行非DEA有效。

**理由**：若将28%的分理处1与72%的分理处3组合，其各项产出均不低于分理处2的各项产出，但其投入量只有分理处2的96.6%。

## 七、本讲小结

1. DEA方法是评价多投入、多产出决策单元相对有效性的重要工具，特别适用于量纲不同、难以直接加总的指标。
2. C²R模型通过构造分式规划，并借助Charnes-Cooper变换转化为线性规划，便于求解。
3. DEA有效性可以从两个角度理解：一是生产前沿面上的点；二是不存在投入不增、产出不减的假想决策单元。
4. 实际应用中，通过求解线性规划得到效率值E，若E = 1则DEA有效；若E < 1则非DEA有效。
