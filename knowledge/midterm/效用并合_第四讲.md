## 二、5.1 多目标决策的目标准则体系

### 2.1 为什么要研究多目标决策

前几章讨论的决策问题大多只有一个目标，评价准则也是单一的，这类问题称为**单目标决策**或**单准则决策**。然而在实际决策中，单目标情形并不多见，更多的是**多目标决策**：

- 多个目标相互联系、相互制约；
- 目标之间可能存在冲突甚至矛盾；
- 形成多层次、结构复杂的多目标准则体系。

因此，解决复杂多目标决策问题的关键，是合理地选择和构造**目标准则体系**。

### 2.2 基本概念

- **决策目标**：决策问题要达到的目标。
- **决策准则**：用数值表示决策方案实现某个目标的标准和法则。

在单目标决策中，决策准则较为简单；在多目标决策中，目标不止一个，每个目标对应的决策准则也可能不止一个，因此更加复杂。

### 2.3 目标准则体系的定义

**目标准则体系**：把决策目标逐层分解，或根据决策主体的要求和实际情况，形成一个多层次结构的子目标系统，使得最底层子目标可以用单一准则进行评价（带有具体数值和单位）。这种结构通常呈**树形结构**，包含一个总体目标，最下一层称为**准则层**。

> 多目标准则分析过程，就是依据某种科学方法，对整个层次目标体系，合理地给出每个可行方案满意程度的数值，即**满意度**。

### 2.4 构建目标准则体系的原则

1. **系统性原则**
   - 各子目标应反映所有因素对涉及经济活动的整体影响；
   - 重视决策问题各环境因素的层次性和相关性；
   - 反映社会经济系统主体框架的内涵特性。

2. **可比性原则**
   - 子目标的分解和设计既要注意不同社会经济系统的横向比较；
   - 又要注意同一系统的纵向动态分析。

3. **可操作性原则**
   - 各子目标评价设计要含义明确、计算简便；
   - 与现行统计指标口径一致，便于采集数据；
   - 在决策信息量充分的前提下，尽量减少子目标个数；
   - 决策分析方法思路清晰，便于在计算机上实现。

### 2.5 目标准则体系的三种结构

#### （1）单层次目标准则体系

- 各目标属于同一层次；
- 每个目标无需再分解，可用单一准则直接给出定量评价；
- 常见于微观经济管理，如企业对设备、装置的技术和经济指标评价。

#### （2）序列型多层次目标准则体系

- 各目标可按序列逐层分解为若干第一层次子目标；
- 各子目标继续分解，一层层按类别有序进行；
- 直到最低一层目标可用某个准则评价。

**特点**：

- 每个子目标均可由相邻上一层次的某个目标分解而成；
- 各子目标按序列关系分属各类目标；
- 不同类别目标之间不发生直接联系；
- 最终所有“叶子结点”目标都可用单一准则评价。

#### （3）非序列型多层次目标准则体系

- 某一层次各子目标一般不单由相邻上一层次目标分解而来；
- 各子目标不能按序列关系简单分类；
- 相邻两层子目标之间仅按自身属性建立联系；
- 有联系的子目标之间用实线连接，无实线的子目标之间不存在直接联系；
- 最终所有“叶子结点”目标都可用单一准则评价；
- 是序列型多层次目标准则体系的**广义形式**。

### 2.6 解决多目标决策问题的两个难点

1. **结构太复杂？**
   - 方法：针对不同结构采用不同方法。

2. **单位（量纲）不统一？**
   - 方法：基于效用，去量纲。

### 2.7 效用评价准则与效用函数

**基本思想**：

将不同度量单位（量纲）的准则，转化为**无量纲**的数量标度，并按特定法则和逻辑过程进行归纳和综合，建立可行方案之间具有可比性的数量关系。

**注意事项**：

1. 效用值介于 0、1 之间；
2. 每个准则的效用曲线用标准测定法计算；
3. 根据某种规则把效用并合起来，得到总体效用。

## 三、5.2 多维效用并合方法

### 3.1 多目标决策问题的两个显著特点

1. **不可公度性**：目标没有统一量纲，不能用统一评价标准直接比较。
2. **矛盾性**：某可行方案提高某一目标值，可能会降低另一目标值。

**解决方法**：建立**多维效用并合模型**。

### 3.2 多维效用并合模型的适用范围

> 注意：多维效用并合方法只能解决可分解为**序列型多层次目标准则体系**的多目标决策问题。

### 3.3 自下而上的逐层并合程序

设经过系统分析，已经构建了序列型多层次目标准则体系：

- 最低一层为**准则层**，各准则按序列关系分属各类；
- 相应效用也分属各类；
- 其他各层次子目标的记号均表示该子目标的**效用值**。

效用并合规则和程序是**由下而上、分类逐层**进行的：

1. **初级并合**：将最低一层各准则的效用值，分类按某种规则并合，得到倒数第二层各子目标的并合效用值。
2. **次级并合**：对初级并合的效用值，分类按某种规则进行第二级并合，得到倒数第三层各子目标的并合效用值。逐层进行，经过多级并合，得到第二层各目标的并合效用值。
3. **总效用并合**：第二层目标效用值按某种规则并合，得到可行方案对整个多层结构目标准则体系的总效用值，作为决策依据。

**总效用值**体现了可行方案关于目标准则体系的整体特征以及对决策主体的偏好，称为可行方案的**满意度**。

### 3.4 多维效用并合的符号表示

设：

- H 表示可行方案的总效用值；
- v₁, v₂, …, vₗ 表示第二层子目标的效用值；
- w₁, w₂, …, wₖ 表示倒数第二层子目标的效用值；
- u₁, u₂, …, uₛ 表示最低一层各准则的效用值；
- 符号“∘”表示按某种规则和逻辑程序进行的效用并合运算。

效用并合过程由下而上、逐层进行。最低一层各准则的效用经过并合得到：

w₁(aᵢ) = u₁(aᵢ) ∘ u₂(aᵢ) ∘ …

w₂(aᵢ) = uₚ(aᵢ) ∘ uₚ₊₁(aᵢ) ∘ …

…

wₖ(aᵢ) = … ∘ uₛ₋₁(aᵢ) ∘ uₛ(aᵢ)

### 3.5 多维效用并合规则

多维效用并合规则可从**二维效用并合规则**导出。常见的多维效用并合规则有：

1. 距离规则
2. 代换规则
3. 加法规则
4. 乘法规则
5. 混合规则

> 难点：分析准则的类型和准则之间的关系，选取合适的并合规则。

#### （一）距离规则

**二维效用并合需满足的条件**：

1. 当二维效用同时达到最大值时，并合效用才达到最大值；
2. 当二维效用同时取最小值时，并合效用取零效用值；
3. 二维效用平面上其余各点效用值，与该点并合效用最大值点的距离成正比。

**数学表达**：设 W = W(u₁, u₂) 是距离规则所确定的二维效用函数，则 W 应满足：

1. W(1, 1) = 1
2. W(0, 0) = 0
3. 0 < W(1, u₂) < 1，0 ≤ u₂ < 1；0 < W(u₁, 1) < 1，0 ≤ u₁ < 1
4. W = W(u₁, u₂) 的取值与距离 d = √[(1 − u₁)² + (1 − u₂)²] 成正比例变化（本质上是点 (u₁, u₂) 与点 (1, 1) 的距离）。

**二维效用并合结果**：

S = W(u₁, u₂) = 1 − √{ (1/2)[(1 − u₁)² + (1 − u₂)²] }

**n 维推广**：

W(u₁, u₂, …, uₙ) = 1 − d/√n = 1 − √{ (1/n) Σᵢ₌₁ⁿ (1 − uᵢ)² }

**应用示例：成本效益分析**

成本效益分析可利用距离规则进行并合。其目标在于寻求成本和效益的最佳组合：成本一定而效益最大，或效益一定而成本最小。

设成本效用和效益效用分别记为 u_C 和 u_E：

- 成本效用曲线是单调下降曲线；
- 效益效用曲线是单调上升曲线；
- 可行方案的最小成本和最大成本分别为 c* 和 c⁰，且 u_C(c*) = 1，u_C(c⁰) = 0；
- 最大效益和最小效益分别为 e* 和 e⁰，且 u_E(e*) = 1，u_E(e⁰) = 0。

二维效用函数 W(u_C, u_E) 满足：

1. W(u_C(c*), u_E(e*)) = W(1, 1) = 1
2. W(u_C(c⁰), u_E(e⁰)) = W(0, 0) = 0
3. 0 < W(u_C(c*), u_E(e⁰)) = W(1, 0) < 1；0 < W(u_C(c⁰), u_E(e*)) = W(0, 1) < 1
4. W(u_C, u_E) 的取值与距离 d = √[(1 − u_C)² + (1 − u_E)²] 成正比例变化。

因此，成本和效益的效用并合应按距离规则进行，并合效用函数为：

W(u_C, u_E) = 1 − √{ (1/2)[(1 − u_C)² + (1 − u_E)²] }

#### （二）代换规则

**二维效用并合需满足的条件**：

1. 二效用对决策主体具有同等重要性；
2. 只要其中一个目标的效用取得最大值，无论其他效用取何值，即使取得最低水平，并合效用也达到最高水平。

**数学表达**：设 W = W(u₁, u₂) 是代换规则所确定的二维效用函数，则 W 应满足：

1. W(1, 1) = 1
2. W(0, 0) = 0
3. W(1, u₂) = 1，0 ≤ u₂ ≤ 1；W(u₁, 1) = 1，0 ≤ u₁ ≤ 1

**二维效用并合公式**：

W(u₁, u₂) = 1 − (1 − u₁)(1 − u₂) = u₁ + u₂ − u₁u₂

**n 维推广**：

W(u₁, u₂, …, uₙ) = 1 − (1 − u₁)(1 − u₂)…(1 − uₙ) = 1 − ∏ᵢ₌₁ⁿ (1 − uᵢ)

#### （三）加法规则

**二维效用并合需满足的条件**：

二效用的变化具有相关性，对并合效用的贡献没有本质差异，并且可以互相线性地补偿。即一目标效用值的减少可以由另一目标效用值的增加得到补偿；完满的总效用只有当二效用值均达到最高水平时才能实现。

**二维效用并合公式**：

W(u₁, u₂) = ρ₁u₁ + ρ₂u₂，其中 ρ₁ + ρ₂ = 1

其中 ρ₁ 和 ρ₂ 是常数，0 ≤ ρ₁, ρ₂ ≤ 1，分别为二效用 u₁、u₂ 的权重系数，表示二效用在各自合并中的重要程度。

**n 维推广**：

W(u₁, u₂, …, uₙ) = ρ₁u₁ + ρ₂u₂ + … + ρₙuₙ = Σᵢ₌₁ⁿ ρᵢuᵢ

其中 0 ≤ ρᵢ ≤ 1（i = 1, 2, …, n），ρᵢ 为第 i 个目标效用 uᵢ 的权系数，且：

ρ₁ + ρ₂ + … + ρₙ = 1

#### （四）乘法规则

**二维效用并合需满足的条件**：

二效用对于合并效用具有同等的重要性，相互之间完全不能替代。只要其中任意一个目标效用值为零，无论另一个目标效用值取多大，并合效用为零。

**二维效用并合公式**：

W(u₁, u₂) = u₁u₂

更一般形式：

W(u₁, u₂) = u₁^ρ₁ · u₂^ρ₂

其中 ρ₁、ρ₂ 为正常数。当 ρ₁ = ρ₂ = 1 时，退化为上述基本形式。

**n 维推广**：

W(u₁, u₂, …, uₙ) = u₁u₂…uₙ = ∏ᵢ₌₁ⁿ uᵢ

更一般形式：

W(u₁, u₂, …, uₙ) = u₁^ρ₁ · u₂^ρ₂ · … · uₙ^ρₙ = ∏ᵢ₌₁ⁿ uᵢ^ρᵢ

#### （五）混合规则

**适用场景**：

混合规则适用于各目标之间关系较为复杂的情况，是比距离规则、代换规则、加法规则和乘法规则更为一般的情况。当上述哪一种规则都不能确定时，可以使用混合规则。

**二维效用并合公式**：

W(u₁, u₂) = c₁u₁ + c₂u₂ + γc₁c₂u₁u₂

其中 γ 称为**形式因子**，γ ≥ −1。γ 取不同值分别表示上述不同情况。

经恒等变换，可得到如下形式：

1 + γW = (1 + γc₁u₁)(1 + γc₂u₂)

**特殊情况**：

- 当 γ = −1 且 c₁ = c₂ = 1 时，公式转化为代换规则形式：W(u₁, u₂) = u₁ + u₂ − u₁u₂
- 当 γ = 0 且 c₁ + c₂ = 1 时，公式转化为加法规则形式：W(u₁, u₂) = c₁u₁ + c₂u₂
- 当 γ >> 0 时，公式近似于乘法规则：W(u₁, u₂) ≈ γc₁c₂u₁u₂

**n 维推广**：

1 + γW = (1 + γc₁u₁)(1 + γc₂u₂)…(1 + γcₙuₙ) = ∏ᵢ₌₁ⁿ (1 + γcᵢuᵢ)

## 四、小结

1. 多目标决策问题的核心难点在于目标多、准则多、量纲不统一、目标间可能冲突。解决思路是构建科学的**目标准则体系**，并引入**效用**进行无量纲化处理。
2. 目标准则体系可分为**单层次**、**序列型多层次**、**非序列型多层次**三种结构，构建时应遵循**系统性、可比性、可操作性**三大原则。
3. 多维效用并合方法适用于**序列型多层次目标准则体系**，计算过程是**由下而上、逐层并合**，最终得到方案的总效用（满意度）。
4. 常用的并合规则包括**距离规则、代换规则、加法规则、乘法规则、混合规则**。选择并合规则的关键在于分析准则类型和准则之间的关系。
